- 🚀 **Founder of [VORA](https://github.com/Vora-bj)** — a software company building SaaS platforms, mobile apps and AI products for businesses.

- 🔥 Passionate about **building scalable applications** and solving real-world problems with clean, tested code.
- 💬 Ask me about **Python, Django, FastAPI, AI, Data Science, SaaS and full-stack development**.

## 🚀 What I'm Building

<a href="https://okmeca.com"><img src="assets/okmeca.png" alt="OkMeca — the all-in-one platform for car repair shops" width="100%"/></a>

**OkMeca** connects customers, mechanics and shop managers in one platform: online quote approval, live repair
tracking, certified invoices, stock, cash register, mobile money and card payments. Mobile app, web workspace and
back-office — built with Django, Next.js and React Native. Launching in 2026.
